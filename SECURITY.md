# Security Policy

## Supported versions

Security fixes target the latest release on the default branch. Older versions may not receive fixes.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private security advisory flow for `keton-id/probelm`:

<https://github.com/keton-id/probelm/security/advisories/new>

Include the affected version, reproduction steps, impact, and any safe mitigation. Do not include gateway API keys, tokens, personal data, or other secrets.

If the private advisory flow is unavailable, contact the maintainers privately through the `keton-id/maintainers` team and request a security channel.

## Response

Maintainers will acknowledge a report, reproduce it, assess impact, and coordinate a fix and disclosure timeline with the reporter. Public disclosure should wait until a fix or mitigation is available.

## Scope

Reports involving credential exposure, unsafe command behavior, dependency vulnerabilities, release artifact integrity, or installer checksum bypasses are in scope. General usage questions and non-security bugs belong in GitHub Issues.
